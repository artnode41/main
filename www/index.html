Im Lieferumfang

Fünf Module — vollständig integriert

01

Kollektionen

Kunstwerke, Provenienzerfassung, KGTG-konforme Prüfprotokolle, Kommissionsteilungen.

02

Verkauf

MWST-konforme PDF-Rechnungen, Payrexx-Zahlungslinks, Differenzbesteuerung. Tablet-Kassensystem für Messestände.

03

Website

Moderne Galerieseite mit Künstlerprofilen, Ausstellungen, Blog und Kontaktformularen. Vollständig mehrsprachig: DE, FR, IT, EN.

04

CRM

Kontakte von Sammlern und Institutionen, Kaufhistorie, Einliefererbeziehungen.

05

Teilen

Kunstwerke auswählen und mit einem Klick einen teilbaren Link erstellen. Kuratierte Auswahlen an Sammler senden — kein Login erforderlich.

Philosophie

Warum Open Source?

Im Gegensatz zu kommerziellen Lösungen, die pro Nutzer, pro Werk oder pro Transaktion abrechnen und Ihre Daten auf eigenen Servern zentralisieren, verfolgt ArtNode einen anderen Ansatz. Die Software ist vollständig frei (MIT-Lizenz): ihr Code ist kostenlos, anpassbar und bleibt es für immer.

Mit ArtNode behalten Sie die Kontrolle: Ihre Daten liegen ausschliesslich auf Ihrem eigenen Hosting. Kein monatliches Abonnement, keine Nutzerbeschränkungen, keine Exportsperre. Sie investieren einmalig in eine professionelle Installation und eine massgeschneiderte Begleitung — und nutzen das Tool danach vollständig autonom, so lange Sie möchten.
